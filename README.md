# 多线程Web服务器

基于epoll事件驱动 + 线程池实现的并发HTTP服务器，支持静态网页返回和在线聊天室功能。

## 功能特性
- 基于epoll事件驱动模型，单线程监听所有客户端连接
- 线程池处理客户端请求，支持并发访问
- 支持HTTP GET/POST方法，返回html、图片等静态资源
- 基于长轮询的在线聊天室，支持多用户实时消息收发
- 历史消息保存，新用户进入可查看之前的聊天记录
- 404错误处理

## 技术栈
C++17 / Linux epoll / 线程池 / 多线程 / HTTP协议 / 长轮询

## 设计思路
1. **epoll**：负责监听所有socket事件，有新连接就accept，有数据就丢给线程池
2. **线程池**：固定数量的工作线程，从任务队列里取客户端请求处理
3. **HTTP解析**：解析请求行，拿到要访问的路径，区分静态文件和聊天室接口
4. **静态文件**：读取www目录下的文件，根据后缀返回对应的Content-Type
5. **聊天室**：基于HTTP长轮询，客户端定时拉取新消息，服务端保存历史消息，加互斥锁保证并发安全

## 为什么用epoll+线程池？
- epoll负责IO事件，不阻塞，单线程处理成千上万连接
- 线程池负责处理请求，充分利用多核CPU
- 比多进程或者每连接一线程效率高，资源占用少
